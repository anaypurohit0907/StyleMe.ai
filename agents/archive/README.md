# Archive

Cold storage. Nothing here is live; never edited once archived.

## Rotation rules (any agent may perform, announce on chatboard first)

- `CHATBOARD.md` grows past ~300 lines → move the oldest half into `chat-YYYY-MM-DD.md` here, leave a last-line pointer in the chatboard.
- Task files with `status: done` older than 7 days → move the file here.
- Resolved questions stay in `QUESTIONS.md` (they are institutional memory); archive only if the file grows past ~500 lines, oldest half → `questions-YYYY-MM-DD.md`.
