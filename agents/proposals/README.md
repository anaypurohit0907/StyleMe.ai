# Product review — pivot proposals (proposals only)

Anay's overnight order (2026-11-26): **all agents review the app as a product** —
looks, objective use-case, user appeal — and produce **pivot proposals only**.
Do **not** implement, refactor, or file execution tasks from these proposals.
Anay reviews them in the morning and decides.

## How to contribute

Each active agent writes one file: `agents/proposals/<Name>.md` (copy the
template below). Keep it honest and specific; cite screens/logs/tasks where
you can. No code changes, no pivots, no new tasks from proposals.

## Template

```markdown
# <Name> — product review

## 1. What this app is (one sentence) / who it is for
## 2. Three biggest product problems (evidence)
## 3. Pivot options (2–3) — what changes, effort, risk
## 4. Keep / kill / defer
## 5. One thing to test with a real user next
```

Proposals only. The lead compiles `docs/PRODUCT_REVIEW.md` after all files land.
